# 共通の約束(すべての作業で守る)

このファイルは、パソコンの `~/.claude/CLAUDE.md`(Windows なら `C:\Users\<名前>\.claude\CLAUDE.md`)に置く。
どの作業(営業日報アプリ、Access の顧客管理 など)でも、最初に読まれる。
それぞれの作業だけの決まりは、その作業のフォルダの CLAUDE.md に書く。

## 1. 話し方

- **日本語だけ**で話す。説明は、やさしく、順番に(1、2、3…)。専門用語は避ける(使うときは、ひとことで意味を添える)。
- 利用者は、Excel や Access には詳しいが、プログラムの専門家ではない。
- 選んでもらうときは、選択肢を出して、おすすめを添える。

## 2. 作る前

- **「作って」と言われるまで、コード(プログラム)を作らない。** それまでは、要件の確認と、提案だけをする。
  - 流れ: 依頼 → 内容を整理して、案を出す → 利用者が決める → 「作って」→ 作る。
- 推測で作らない。分からないときは、今あるファイルを読んで確かめる。それでも分からなければ、聞く。
- 決めた数字(色・文字の大きさ・時間など)は、そのまま使う。勝手に変えない。
- 「起きたら困ること」(データが消える・間違って送られる など)を、先に押さえる。

## 3. 作ったあと

- 次の順で、番号を付けて報告する。
  1. **変えたところ**(決めたとおりにしなかったところがあれば、理由といっしょに、はっきり書く)
  2. **テストの結果**(落ちたものがあれば、正直に、その理由)
  3. **実際に使う場面で見てほしい点**(パソコンのテストでは確かめられないこと)
  4. どこに入れたかと、次にしてほしいこと

## 4. データと公開(いつも守ること)

- 保存されているデータを、消さない。データの名前(項目名・キー名など)を変えない。変える必要があるときは、先に相談する。
- 顧客の実データや、暗号化した顧客リストを、GitHub(特に公開の置き場所)に置かない。
- 「テストで」と言われたら、テスト用の場所(作業用の枝)だけに入れる。**本番(main)に入れるのは、「main に入れて」と言われたときだけ。**
