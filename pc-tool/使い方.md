# 日報取り込みツール 使い方

スマホの営業日報アプリから送ったCSVを、Excelの「営業日誌」に転記するツールです。
日々のシート(1～31日)に書き込むと、**運転管理表**は原紙の数式で自動的にできあがります。

## できること

| 書き込む場所 | 内容 |
|---|---|
| 日々のシート(1～31) | 時間(開始～終了)・行先・面談者・用件・**ToDo**・備考(特記事項) |
| 日々のシートの下 | 出発(メーター)・帰着(メーター)・給油 |
| 運転管理表 | 年月・曜日を自動で設定。距離・給油・主な行先は原紙の数式で集まる |
| ToDoリスト(新しいシート) | その月に登録・完了したToDoの一覧(未対応も済みも) |

- 原紙は書き換えません。月ごとに「営業日誌_2026年11月_名前.xlsx」を作り、2回目からは同じファイルに書き足します。
- 「用件」の欄の右半分を「ToDo」の列にしています。その日に訪問した客先のToDoを出します(□=未対応、済(11/11)=済ませた日)。

## 最初に1回だけ(設定)

1. このフォルダごと、PCやUSBの好きな場所に置く
2. `日誌原紙.xlsx` を、このフォルダ(ツールと同じ場所)に入れる
3. `日報取り込みツール.xlsm` を開く(上に「コンテンツの有効化」が出たら押す)
4. 「設定」シートの **担当者名** に、スマホのアプリに登録した名前と同じ字を入れる
   - ほかの3つ(日誌原紙のファイル・CSVを置くフォルダ・日誌の保存先フォルダ)は、**空欄のままでよい**
5. 上書き保存する

### フォルダごと持ち歩ける

- ツールは、開いたときに**ツールが今あるフォルダ**を元に、次の場所を使います。
  - `日誌原紙.xlsx`(原紙)
  - `CSV` フォルダ(CSVを置く)
  - `営業日誌` フォルダ(できあがった日誌)
- USBのドライブ名が変わっても、別のPCに移しても、そのまま使えます。
- 設定で「選ぶ」を押して、このフォルダの中のものを選んだときは、フォルダから見た書き方(例: `日誌原紙.xlsx`)で残します。フォルダの外を選んだときは、その場所をそのまま使います。
- OneDrive の画面(Web)から開くと場所が分からないので、使えません。

## スマホの準備(最初に1回だけ)

1. アプリを開くと「使う人の登録」が出る。名前と送り先のメールアドレスを入れて「登録」を押す
2. あとで直すときは、データ画面の一番上の「使う人」→「登録・変更」

## 毎日(または、まとめて)

1. スマホのデータ画面で「全データをメール送信(CSV添付)」を押す
2. 共有の画面で「メール」を選び、宛先の欄に**貼り付け**(アドレスはコピー済み)て送る
3. 送れたら、スマホで「送信済みにする」を押す(完了したToDoは、リストから外して自動保存されます)
4. PCで、届いたメールの添付(`訪問_`・`車両_`・`ToDo_` で始まるCSV)を「CSVを置くフォルダ」に保存する
   - 容器ログのCSVは保存しなくてよい
   - メールソフトの「添付ファイルをすべて保存」を使うと楽です
5. ツールの「CSVを取り込む」を押す

## 月初(毎月1日以降)

1. スマホのホームと車両の画面の上に「○月分の運転日報を、メールで送ってください」が出る
2. 「○月分を送る(CSV添付)」を押して、同じように送る
3. 「送れましたか?」で「OK」を押すと、お知らせが消える
4. PCで、届いたCSVを保存して「CSVを取り込む」を押す
   - 月分のCSVで、その月の訪問を**全部入れ替え**ます(スマホで直した・消した訪問も反映)
5. できあがった営業日誌の「運転管理表」を確認して提出する

> 先月分を送るまでは、スマホで先月のデータを「消す」で消さないでください。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 「途中で止まりました」と出た | 営業日誌のファイルを開いたままにしていないか確認。閉じてから、もう一度押す(CSVは移していないので、そのままでよい) |
| 「担当者が違う」と出た | 他の人のCSVが入っている。そのCSVを手で消す(または本人に渡す) |
| 「18件を超えた分は書けません」と出た | 1日の行は18行まで。超えた分は手で書き足す |
| 同じCSVを2回入れてしまった | 大丈夫。二重にはなりません |
| 取り込んだCSVはどこ? | 「CSVを置くフォルダ」の中の「取り込み済み」フォルダ(消していません) |
| 手で書いた日の内容は? | CSVに入っていない日は、触りません |

## 確かめ方(初めて使うとき)

1. 1日分だけスマホから送って取り込む
2. 営業日誌を開き、その日のシートと運転管理表の行を見る
3. 問題なければ、ふだんの使い方に進む

## ファイル

- `日報取り込みツール.xlsm` … ツール本体(配るのはこれと、この使い方)
- `日誌原紙.xlsx` … 原紙(各自で入れる。客先名が入っているので、GitHubには置かない)
- `CSV\` … メールのCSVを置く(取り込んだCSVは `CSV\取り込み済み\` に移る)
- `営業日誌\` … できあがった日誌
- `src\M_取り込み.bas` … マクロの中身(直すとき用)
- `src\build.ps1` … ツールを組み立て直す手順(直すとき用。ふだんは使わない)
