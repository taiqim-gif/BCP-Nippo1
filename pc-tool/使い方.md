# 営業日報 取り込み 使い方(Access版)

スマホの営業日報アプリから送ったCSVを `営業日報.accdb` にため、担当者ごとに見たり、Excelの「営業日誌」を作ったりします。
何人分のデータも1つのファイルにためます。

> 前の Excel版(`日報取り込みツール.xlsm`)は `アーカイブ_Excel版\` に移しました(2026-11-18)。ふだんは使いません。中の `説明書.md` を見てください。

## 日誌原紙の形(2026-11-18 から)

- 原紙の場所は `初期設定用紙入れ\日誌原紙.xlsx`(2026-11-25 から)
  - ほかの人が消したり直したりしにくいよう、**読み取り専用**にしてあります
  - 直すときは、ファイルを右クリック →「プロパティ」→「読み取り専用」のチェックを外す。直したら、またチェックを付ける
  - ここに無いときは、前の場所(`営業日報.accdb` と同じフォルダ)の原紙を使います
- `日誌原紙.xlsx` は「Sheet1」(1日分のひな形)と「運転管理表」の2枚
- 月のファイルを作るとき、ひな形は隠したシート「_ひな形」になり、これをコピーして日付のシートを作ります
- ひな形の年月日・曜日・担当者氏名は、プログラムが書き込みます
- 1日分のシートは **1項目=1列**(A～Kの11列。A4横1枚で印刷)
  - A=No / B=顧客コード / C=開始 / D=～ / E=終了 / F=行先 / G=面談者 / H=用件 / I=ToDo / J=備考 / K=確認印
  - 下の行(25行目): G25=出発メーター / I25=帰着メーター / K25=給油
- 原紙を作り直すとき: `プログラム_直すとき用\make_template.ps1` を実行(運転管理表はそのまま。読み取り専用は自動で外して、また付けます)
- 前の原紙(細かい列の形)で作った月のファイルには書きません。そのファイルをバックアップに移してから作り直してください
- 原紙は書き換えません。月ごとに「営業日誌_2026年11月_名前.xlsx」を作ります

## 最初に1回だけ

1. `初期設定用紙入れ` フォルダに `日誌原紙.xlsx` を入れる(読み取り専用にする)
2. `営業日報.accdb` を開く
3. 上に「セキュリティの警告」が出たら「コンテンツの有効化」を押す
   - 毎回出るのが面倒なら、Access の「ファイル」→「オプション」→「トラスト センター」→「トラスト センターの設定」→「信頼できる場所」に、このフォルダを足す
4. 自分の名前が一覧に無いときは「担当者を追加」で入れる
   - 名前は、スマホのアプリの「使う人」に登録した名前と**同じ字**にする
   - 取り込むときは、CSVの中の「担当者」の名前で分けます(古い形のCSVは、ファイル名「日報_〇〇_日付.csv」の〇〇)
   - 空白はあってもなくてもよい(「苫小牧 佐藤」と「苫小牧佐藤」は同じ人)
5. 「担当者の設定(車両No.)」で、担当者ごとの**車両ナンバー**を入れる(運転管理表に出ます)
   - 「③ まとめて取り込む」をすると、CSVの名前から自動で足されます

### スマホの準備(最初に1回だけ)

1. アプリを開くと「使う人の登録」が出る。名前と送り先のメールアドレスを入れて「登録」を押す
2. あとで直すときは、データ画面の一番上の「使う人」→「登録・変更」

### フォルダごと持ち歩ける

- `営業日報.accdb` は、**自分が今あるフォルダ**の `初期設定用紙入れ\日誌原紙.xlsx`・`CSV`・`営業日誌` を使います
- 持ち歩くときは、1つ上の `営業日報` フォルダごと持ち歩きます。手順とデータの流れの図は、`営業日報\はじめに読む_使い方.md` を見てください
- OneDrive の画面(Web)から開くと場所が分からないので、使えません

## 毎日(または、まとめて)

1. スマホのデータ画面の「送る」→「毎日」の「まだ送っていない分を送る」を押す
2. 共有の画面で「メール」を選び、宛先の欄に**貼り付け**(アドレスはコピー済み)て送る
   - 添付は2つ: `日報_名前_日付.csv`(訪問・車両・ToDo・容器が1つに入っている)と、`営業日報バックアップ_日付.json`(スマホのバックアップ)
3. 送れたら、すぐ下の「送れたら押す：送信済みにする」を押す
4. PCで、届いたメールの `日報_` で始まるCSVを `CSV` フォルダに保存する
   - バックアップ(.json)は、メールに残しておけばよい
5. `営業日報.accdb` で、担当者で自分を選んで「② 自分の分を取り込む」
   - まとめて入れるときは「③ まとめて取り込む(全員)」。名前ごとに自動で分かれます
   - 前の形の4つのCSV(`訪問_`・`車両_`・`ToDo_`・`容器ログ_`)も読めます
   - 「自分の分」のときは、ほかの人のCSVは、そのまま残ります
   - 取り込んだCSVは `CSV\取り込み済み\` に移ります(消していません)

## 月初(毎月1日以降)

スマホ:

1. ホームと車両の画面の上に「○月分の運転日報を、メールで送ってください」が出る
2. 「○月分をまとめて送る(CSV添付)」を押して、同じように送る
3. 「送れましたか?」で「OK」を押すと、お知らせが消える
4. 続けて「○月分を、スマホから消します」と出る。件数を見て「OK」を押すと、その月の訪問・車両・容器と、済んだToDoをスマホから消す
   - まだ済んでいないToDoは、スマホに残ります
   - 消したくないときは「キャンセル」(何も消しません)

> 必ずメールが届いたことを確かめてから「OK」を押してください(バックアップはメールに添付されています)。

PC:

1. 届いたCSVを `CSV` に保存して「② 自分の分を取り込む」(その月の分がまるごと新しくなる)
2. 担当者を選ぶ(「(全員)」なら、その月にデータがある人の分を全部作る)
3. 年月を選ぶ(最初は、月の1～5日は先月、6日からは今月になっています)
4. 「営業日誌を作る」→ `営業日誌\2026年度` フォルダに「営業日誌_2026年11月_名前.xlsx」ができる
   - 年度(4月～翌年3月)ごとのフォルダに入ります。新しい年度の4月分を初めて作ったときに、フォルダが自動でできます(例: 2027年4月分 → `2027年度`)
5. Excelで開いて、確かめて印刷する(運転管理表の走行距離も入っています)
   - もう一度押すと、同じファイルに書き直します。手で書いた日(取り込んだデータの無い日)は触りません

営業日誌の中身:

- 日々のシート
  - 平日 … いつも出す
  - 土日・祝日 … データがある日(または手で書いた日)だけ出す。ほかは**非表示**(印刷に出ない)
  - 祝日は自動で計算(振替休日・国民の休日も)
  - 顧客コードは **B列**(A列は 1～18 の番号)。「ToDo」の列には、その日に訪問した客先のToDo(□=未対応、済(11/11)=済ませた日)
- 「運転管理表」… 毎日の始業/終業メーター・主な行先・走行距離・給油
- 「車両・天気」… 毎日の天気・出発/帰社の時刻・走った時間・走行距離・給油の一覧と合計
- 「ToDoリスト」… その月に登録・完了したToDoの一覧
- 「容器ログ」… その月の容器ログの一覧(容器ログがある月だけ)

## 分析

1. 担当者と「年度」を選ぶ(4月～翌年3月。2026年度 = 2026年4月～2027年3月。最初は今の年度)
   - 訪問回数の月の列は、4月～3月の順です
2. 見たいボタンを押す
   - 訪問回数(客先×月)/訪問の一覧/走行距離・時間(月別。走った時間の合計と1日の平均)
   - 車両・天気の一覧(毎日。曜日に祝日・休みの印)
   - ToDo 未対応(経過日数つき)/ToDo 済ませるまでの日数(月別)/ToDo 客先別の件数
   - 容器ログの一覧
3. 開いたまま担当者や年度を変えると、出し直します
4. 緑のボタン「今開いた「分析」をExcelで表示する」で、`営業日誌\2026年度` フォルダ(上で選んでいる年度のフォルダ。無ければ自動でできる)に Excel で保存して開きます
5. 客先の名前は、顧客コードから **今の名前**(同じ顧客コードで、いちばん新しい訪問の名前)で出します。客先の名前が変わっても、過去の分も今の名前にそろいます(顧客コードが無い客先は、入力した名前のまま)

## 上長の承認(2026-11-18 から)

最初に1回だけ:

1. メニューの「上長の登録」を押す
2. 承認する人の「名前」を入れる(何人でもよい)。「名字」は確認印欄に出る字。空なら、名前の空白の前(「山田 一郎」→「山田」)

承認するとき(1日ずつでも、何日分まとめてでもよい):

1. メニューの「担当者」で、承認する人の日報を選ぶ(「(全員)」なら全員分)
2. 「日報を承認する(上長)」を押す
3. 「承認する人」で自分の名前を選ぶ
4. 「まだ承認していない日」から、承認する日を押して選ぶ(もう一度押すと外れる。「すべて選ぶ」もある)
5. 「選んだ日を承認する」を押す → 「はい」
6. 「営業日誌(Excel)の確認印欄にも、今書きますか?」→「はい」で、その月の営業日誌を作り直して書く
   (営業日誌のファイルを開いていると書けません。閉じてから押してください)

- 確認印欄(K列)に「名字 月/日」(承認した日)が入ります。訪問のある行すべてに入ります。訪問が無い日(車両だけ)は1行目
- 1日につき承認は1件だけです(同じ日が二重にならない)。承認した日は、一覧に出なくなります
- 取り消し・差し戻しはできません
- 承認した日を見るときは「承認済みの一覧」(上の「年度」で分かれます)。「ユーザー番号」の列に、承認したPCのログインの番号が出ます(2026-11-25 より前に承認した分は空)
- 承認した日の確認印欄は、書く前にいったん消します(手で書いたものも置き換わります)。承認していない日は触りません

## 困ったとき

| こんなとき | どうする |
|---|---|
| 営業日誌が作れない・書けない | 営業日誌のファイルを開いたままにしていないか確認。閉じてから、もう一度押す |
| 「18件を超えた分は書けません」と出た | 1日の行は18行まで。超えた分は手で書き足す |
| 同じCSVを2回入れてしまった | 大丈夫。二重にはなりません |
| 取り込んだCSVはどこ? | `CSV\取り込み済み\` フォルダ(消していません) |
| 手で書いた日の内容は? | 取り込んだデータの無い日は、触りません |

## 注意

- Access版は、使い始めた日からの分だけです(前の月の営業日誌は入っていません)
- フォルダごと共有フォルダに移せば、ほかの人のPCからも使えます
- 担当者で分けるのは「表示」だけです。ファイルを直接開けば、全員分が見えます

## ファイル

- `営業日報.accdb` … 本体(データもここにたまる。ときどきコピーしてバックアップを)
- `初期設定用紙入れ\日誌原紙.xlsx` … 原紙(読み取り専用。客先名が入っているので、GitHubには置かない)
- `CSV\` … メールのCSVを置く(取り込んだCSVは `CSV\取り込み済み\` に移る)
- `営業日誌\2026年度\` … できあがった日誌・分析のExcel(年度ごとに自動でできる)
- `アーカイブ_Excel版\` … 前の Excel版(使わない。`説明書.md` 付き)
- `プログラム_直すとき用\` … Access のプログラムの元(設計図)。ふだんの取り込み・営業日誌づくりには使わない。ほかの人に渡すときは入れなくてよい
- `プログラム_直すとき用\access\M_Nippo.bas` … マクロの中身(直すとき用)
- `プログラム_直すとき用\access\M_Build.bas`・`build_access.ps1` … 組み立てる手順(直すとき用。ふだんは使わない)
  - ファイルが無ければ新しく作る。あれば `(ユーザーフォルダ)\Backup`(例: `C:\Users\自分のID\Backup`)にコピーしてから新しい版にする(ためたデータは残る。開いている人がいると止まる)
- `プログラム_直すとき用\make_template.ps1` … 日誌原紙の1日分のひな形を作り直す
